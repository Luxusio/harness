# Mise-managed plugin Python

Harness and wiki-atlassian installation select a validated mise base Python
instead of persisting the installer's project virtual environment. Canonical
MCP/hook commands pin that interpreter; portable templates guard mise selection
before product execution. Prerequisite failures preserve existing installations.
Native Windows acceptance remains separate from Linux and modeled path checks.
See the [requirement](../harness/REQ__python-native-wiki.md#mise-managed-installed-interpreters).
