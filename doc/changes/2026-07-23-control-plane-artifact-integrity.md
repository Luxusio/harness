# Control-plane artifact integrity

Harness control-plane writes are now confined to canonical task and Goal paths, and bundled plan writes validate every supplied artifact before changing the task pack. TASK_STATE, Goal, CHECKS, AUDIT, and active-marker reads reject symlinked or special-file leaves without blocking. Unknown tasks cannot leave orphan `BLOCKED.md` files, malformed or non-regular present CHECKS ledgers block reconciliation and close instead of behaving like a missing legacy ledger, and AC promotion preserves timestamps and nested indentation. Active-task routing also ignores terminal per-session markers, rejects identity-mismatched marker payloads, and falls back to the live legacy marker, preventing long-lived sessions from sending hooks and tests to an already closed task. Existing bare task IDs, canonical relative or absolute task paths, flat and wrapped CHECKS layouts, and pre-state legacy `.active` markers remain supported.
